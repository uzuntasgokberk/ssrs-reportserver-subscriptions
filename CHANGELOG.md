# Changelog

All notable changes to this project are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Repository contribution and agent rules: scoped branches, required pull requests and CI, invitation-only external contributions, and maintainer-controlled merging.
- Pull request and issue templates, code ownership, private-reporting guidance, and an importable default-branch ruleset with publication instructions.

### Changed

- CI uses read-only repository permissions, a pinned checkout action without persisted credentials, a timeout and cancellation of superseded runs.
- Documentation explicitly separates RDL scope and SSRS live-test evidence from Power BI Report Server compatibility that still needs a live check.

## [1.0.0] - 2026-11-11

### Added

- Bulk creation of SSRS e-mail subscriptions from an Excel file, one row per subscription, using the `ReportService2010` SOAP API.
- Preview by default; `-Apply` changes the report server only if every row passed the pre-check (all or nothing).
- Subscriptions with the same name on the same report are skipped; `-Overwrite` updates them from the Excel row (the subscription ID is kept) and leaves matching ones unchanged.
- Schedules: `Daily`, `Weekly` (chosen days, `Weekdays`, `Weekend`), `Monthly` (days of the month), `Hourly` (every 1-24 hours) and `Once`.
- To, Cc, Bcc, subject, comment, render format and link to the report.
- Report parameters, validated live on the report server before anything is written; valid values are listed for missing or invalid ones.
- Checks of the report path, data source credentials and the e-mail delivery extension.
- Last-second check before each write, and read-back verification after it.
- Log file and CSV per run; exit codes for schedulers.
- Excel template with example rows and a "How to use" sheet, generated by `tools/New-SubscriptionTemplate.ps1`.
